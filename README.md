# SG-SST Manager – Prototipo

## 📌 Descripción
Prototipo funcional de un Sistema de Gestión de Seguridad y Salud en el Trabajo (SG-SST) desarrollado con TypeScript, HTML5 y CSS3 puro (sin frameworks).  
Sigue una arquitectura **inside-out** (de adentro hacia afuera) y está enfocado en **Mobile First**.

## 🚀 Requisitos previos
- [Node.js](https://nodejs.org/) (v24.18.0 o superior)
- npm (v11.8.0 o superior)
- Visual Studio Code (con extensiones recomendadas: ESLint, Prettier, Live Server)

## 📦 Instalación
1. Clona o descarga este repositorio.
2. Abre la carpeta en VS Code.
3. Abre la terminal integrada (PowerShell) y ejecuta:

```bash
npm install
